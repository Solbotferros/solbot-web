In this project, we carried out the installation of a custom hinged metal security grille for a window located inside a home in Vilassar de Mar.

The aim was to improve the security of the opening without compromising natural light or the functionality of the window. For this reason, a hinged solution was designed, allowing the grille to be opened when needed and making access and maintenance easier.

The structure was adapted to the dimensions of the opening and the configuration of the space, ensuring proper fixing and comfortable operation in daily use. This type of solution requires precise installation and good integration with the existing elements.

The result is a practical and discreet metal security grille that provides safety without altering the brightness or aesthetics of the interior space.
